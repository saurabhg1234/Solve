## Stage 5: sign-off evidence

Record each case, source hash, locked baseline/version, actual output filenames/hashes, reviewer run IDs, coverage element counts, findings, fixes, gate decisions, release approver and send/submission action. Keep an internal log separate from the client deliverable.

Pass criteria include zero unrequested commitments, zero internal cost leaks, zero contradictory claims reaching document review, 100% baseline requirement mapping with approved deviations reported separately, zero invented slides and zero already-answered RFI questions. Measure turnaround, review time, escapes and effort accuracy on the first 3–5 pursuits before selecting improvement targets.

Mark blocked/unrun scenarios explicitly. All eight workflows must pass before claiming the agreed first pilot is complete.
